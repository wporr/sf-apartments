# Seen listings

Append-only log of every listing the daily sweep has already reported.
The sweep reads this file first and only reports listings whose URL is NOT already here.

Format — one line per listing:

`YYYY-MM-DD | $PRICE | Address or cross-streets, Neighborhood | URL`

Keep entries even after a listing is gone; the point is to remember what was already shown.
